# Repo Navigation Skill

Use this skill when the user asks where something is implemented, what file contains a class/function, or how repo components connect.

When answering:
1. Start with the direct location.
2. Include exact file paths.
3. Include class/function/method names.
4. Include line numbers if retrieved facts provide them.
5. Mention related files only after the primary answer.
6. Do not give vague architecture discussion before giving the location.

Preferred answer format:
- Primary location
- Related files/classes
- How they connect
